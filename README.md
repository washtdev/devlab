# Devlab🧪

## 🤔 What is it?

Devlab is a platform for prototyping code, enabling developers to quickly test ideas and share them with the community in a fast and intuitive coding environment.

## 🚀 Getting Started

### 📦 Installation

To install dependencies, enter the project directory and run: 

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

### 🏃 Running

After installation, start the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to see the project in action.

## 🛠️ Technologies Used

- Next.js
- Typescript
- TailwindCSS
- Prisma (for database)
- NextAuth (for authentication)
